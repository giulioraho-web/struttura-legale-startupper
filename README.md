# SmartSorter

Benvenuti nel mio repository! Questo progetto è stato sviluppato da **Giulio Raho** e **Giulio Cervelli**

> [Hai presente quella cartella "Download" piena di PDF, immagini, file zip e documenti sparsi? SmartSorter è un leggerissimo script in Python nato per risolvere esattamente questo problema.
